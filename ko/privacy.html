SweepZen 앱

SweepZen은 파일 및 앱 정보를 사용자의 Mac에서 처리합니다. 파일, 경로, 스캔 결과, 사용 활동, 기기 식별자 또는 개인정보를 개발자에게 수집하거나 전송하지 않습니다. 계정, 광고, 타사 분석 SDK 또는 추적 기능이 없습니다.

앱에는 네트워크 클라이언트 권한이 없으며 네트워크 요청을 보내지 않습니다. 지원 또는 개인정보 링크는 시스템 브라우저에서 열립니다.

로컬에서 사용하는 정보

스캔, 저장 공간 지도 또는 앱 검토를 요청하면 SweepZen은 파일 이름과 경로, 크기와 날짜, 앱 메타데이터 및 실행 중인 앱 정보를 읽습니다. 디스크 사용을 설명하고 사용 중인 데이터를 보호하기 위한 것입니다. 일부 설정 및 출처 파일도 로컬에서 읽어 데이터의 소유 관계를 확인합니다. 앱의 보조 프로그램이 종료되거나 다시 시작되는 시점을 확인하기 위해 백그라운드 프로세스 이름과 실행 파일 경로도 확인합니다.

폴더 접근은 macOS가 허용합니다. 보안 범위 폴더 북마크와 언어, 모양, 마지막 정리 완료 날짜 등의 환경설정은 사용자의 Mac에 저장됩니다. 잔여 데이터를 식별하기 위해 목록에 표시한 앱의 식별자와 이름도 기억합니다. 스캔 결과와 선택 항목은 사용 중 메모리에 보관합니다. 정리 목록은 사용자가 내보낼 때만 선택한 위치에 저장합니다.

SweepZen 내에서 제거한 항목은 macOS 휴지통으로 이동합니다. 앱은 휴지통을 자동으로 비우지 않습니다. 폴더 접근을 허용한 후에도 macOS가 일부 파일의 접근을 제한할 수 있습니다.

복사 버튼을 선택하면 SweepZen은 표시된 검색 이름, 경로 또는 명령을 시스템 클립보드에 기록하여 다른 앱에 붙여넣을 수 있게 합니다. 기존 클립보드 내용을 읽거나 복사한 텍스트를 개발자에게 보내지 않습니다.

지원 메시지

개발자에게 이메일을 보내면 이메일 서비스가 주소, 메시지 및 첨부 파일을 처리합니다. 이 정보는 답변과 문제 해결에 사용하며, 지원과 적용되는 의무에 필요한 기간 동안만 보관합니다. 개인 파일, 비밀번호 또는 민감한 정보를 가리지 않은 스크린샷은 보내지 마세요.

GitHub 이슈는 공개되며 GitHub가 자체 개인정보 처리방침에 따라 처리합니다. 대신 이메일을 이용할 수 있습니다. 지원 이메일 삭제를 요청하려면 개발자에게 연락하세요. 단, 적용되는 보관 의무가 있을 수 있습니다.
