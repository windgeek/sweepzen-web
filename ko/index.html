도움말 및 지원

Mac 공간을 더 명확하게.

무엇이 공간을 차지하는지 이해하고, 지울 수 있는 항목을 검토한 뒤 직접 결정하세요.

01 / 스캔

정리하기 전에 검토

앱 캐시와 빌드 결과물을 스캔합니다. 각 항목의 용도와 제거하면 달라지는 점을 설명합니다.

02 / 탐색

전체 공간을 한눈에

저장 공간 지도를 카테고리별로 살펴보고 폴더를 따라가며 공간을 많이 차지하는 파일을 찾습니다.

03 / 제거

지울 항목은 직접 선택

앱과 관련 파일을 검토합니다. 공유 데이터는 보호하며, SweepZen에서 제거한 항목은 휴지통으로 이동합니다.

시작하기

  1. macOS 14 이상을 사용하는 Mac에서 SweepZen을 엽니다.
  2. ‘스캔 및 정리’, ‘저장 공간 지도’ 또는 ‘제거’를 선택합니다. ‘백그라운드 및 확장 프로그램’과 도구 모음에서는 별도의 검토 및 문제 해결 기능을 제공합니다.
  3. macOS에서 요청하면 홈 폴더 접근을 허용합니다. 앱 제거나 임시 파일 검토에는 다른 폴더의 접근 권한이 필요할 수 있습니다. 권한은 이 Mac에 저장됩니다.
  4. 각 결과와 상세 내용을 확인하고 제거할 항목을 선택합니다. 공유 데이터와 소유 관계를 확인할 수 없는 항목은 보호합니다.
  5. 확인 목록을 검토한 뒤 선택한 항목을 휴지통으로 이동합니다.

자주 묻는 질문

왜 여유 공간이 늘어나지 않나요?

휴지통에 있는 파일은 일반적으로 계속 공간을 차지합니다. Finder에서 파일을 확인하고 필요 없다는 확신이 들면 직접 휴지통을 비우세요. APFS 공유 저장 공간과 로컬 스냅샷도 확보되는 공간에 영향을 줄 수 있습니다. SweepZen은 휴지통을 비우거나 Time Machine 스냅샷을 삭제하지 않습니다.

파일을 복원하려면 어떻게 하나요?

Finder에서 휴지통을 엽니다. ‘다시 넣기’를 사용할 수 있으면 선택하거나, 파일을 원래 위치로 이동하세요. 휴지통을 통한 복원은 휴지통을 비우기 전까지만 가능합니다.

왜 일부 항목을 건너뛰거나 유지하나요?

보호된 파일, 공유 데이터 및 다른 앱 사본이 아직 사용할 수 있는 데이터는 유지합니다. Applications 밖의 사본도 확인합니다. 다른 사본이 사용하는 잔여 데이터에는 위치와 유지 이유가 표시되며 제거 대상으로 선택할 수 없습니다. 소유 관계나 접근 권한을 확인할 수 없는 경우에도 항목을 유지합니다.

폴더 접근 권한을 다시 허용하려면 어떻게 하나요?

SweepZen 설정을 열고 해당 폴더 접근을 다시 허용하세요. 스캔에는 홈 폴더를 선택합니다. macOS가 일부 위치를 계속 제한할 수 있으며, SweepZen은 이 제한을 우회할 수 없습니다.

앱 제거에 Applications 접근 권한이 필요한 이유는 무엇인가요?

응용 프로그램 폴더에는 별도 접근 권한이 필요합니다. SweepZen이 요청하면 응용 프로그램 폴더 접근을 허용하세요. 폴더 접근 권한으로 관리자 권한을 얻을 수는 없습니다. 관리자가 설치한 앱은 Finder에서 보기를 선택하고 휴지통으로 옮긴 다음, macOS가 요청하면 인증하세요. 이후 SweepZen으로 돌아와 관련 데이터를 검토하세요. 앱 관리와 전체 디스크 접근 권한은 별개의 시스템 권한이므로 앱에서 필요하다고 안내할 때 해당 설정을 여세요.

SweepZen이 시스템 항목을 제거할 수 있나요?

관리자 권한이 필요한 항목은 Finder에서 표시할 수 있지만 SweepZen이 제거할 수는 없습니다. 도구 모음의 명령은 효과와 비용을 설명합니다. 직접 복사하여 실행해야 하며, SweepZen은 관리자 명령을 실행하지 않습니다.

백그라운드 항목과 Finder 메뉴는 어떻게 처리하나요?

SweepZen은 백그라운드 앱, 확장 프로그램 및 Finder 메뉴 항목의 출처를 보여 줍니다. 필요하면 macOS 설정이나 서비스 중지 안내를 따르세요. 일반적인 파일 형식을 여는 기본 앱은 SweepZen에서 직접 선택할 수 있습니다. 이 도구들은 시스템 메뉴 등록 항목을 자동으로 삭제하지 않습니다.

SweepZen이 내 파일을 업로드하나요?

아니요. 앱은 파일 정보를 로컬에서 처리하고 네트워크 요청을 보내지 않습니다. 계정, 광고, 분석 또는 업로드 서비스도 없습니다. 웹사이트 호스팅과 지원 메시지 처리 방식은 개인정보 처리방침에서 별도로 설명합니다.

보조 프로그램을 종료했는데 왜 계속 제거할 수 없나요?

앱에는 여러 보조 프로그램이 있거나 프로그램이 다시 시작될 수 있습니다. 작업을 저장하고 종료 방법을 펼친 뒤 검색할 이름을 복사하여 활성 상태 보기에서 찾으세요. 터미널 방식은 선택 사항인 고급 방법입니다. SweepZen은 선택한 앱을 2초마다 확인하고 창으로 돌아올 때도 확인합니다. 필요하면 다시 확인을 선택하세요. 다른 보조 프로그램이 남아 있으면 현재 이름이 표시됩니다. 종료해도 제거가 자동으로 시작되지는 않습니다. 화면을 검토하고 확인한 다음 계속하세요.

제거하기 전에 로그인 항목 및 확장 프로그램을 확인해야 하나요?

일반적으로 필요하지 않습니다. 앱에 로그인 구성 요소가 있다고 해서 활성화되어 있다는 뜻은 아닙니다. 제거 후 항목이 계속 표시되거나 로그인 시 실행 방식을 바꾸고 싶을 때만 설정을 확인하세요. 항목이 있다고 해서 앱이 실행 중인 것은 아닙니다. 이 목록은 macOS가 관리하며, 휴지통을 비워도 항목이 즉시 사라진다는 보장은 없습니다. 필요하면 설정에서 제공하는 스위치나 제거 버튼을 사용하세요.
