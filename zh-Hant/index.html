使用說明與支援

看清空間，再決定清理哪些。

了解儲存空間被什麼占用，核對每一項，由你決定刪除哪些內容。

01 / 掃描

刪除之前，先看懂

掃描 App 快取與建置產物。每一項都解釋用途，以及移除後會發生什麼。

02 / 探索

空間去哪了，一眼看清

依類別查看空間透視，再逐層開啟檔案夾，找到真正占空間的內容。

03 / 移除

移除得乾淨，保留得明白

核對 App 和相關檔案。共用資料受到保護，App 內移除的項目進入垃圾桶。

開始使用

  1. 在執行 macOS 14 或更新版本的 Mac 上開啟 SweepZen。
  2. 選擇「掃描清理」「空間透視」或「解除安裝 App」。「背景與延伸功能」和系統工具提供獨立的檢查與故障排除功能。
  3. macOS 提示時，授予個人檔案夾的存取權限。移除 App 或檢查暫存檔案可能需要額外的檔案夾授權，授權儲存在本機。
  4. 查看每項結果及詳細資訊，再選擇要移除的內容。共用資料及無法確認歸屬的項目會受到保護。
  5. 核對確認清單後，將所選項目移到垃圾桶。

常見問題

為什麼可用空間沒有增加？

移到垃圾桶通常不會釋放檔案占用的空間。請先在 Finder 中確認檔案，確定不再需要後自行清空垃圾桶。APFS 共用儲存空間與本機快照也會影響實際釋放的空間。SweepZen 不會清空垃圾桶，也不會刪除 Time Machine 快照。

如何還原檔案？

在 Finder 中開啟垃圾桶，使用可用的「放回原處」操作，或將檔案移回原來的位置。清空垃圾桶後，無法再透過垃圾桶還原。

為什麼有些項目被略過或保留？

受保護的檔案、共用資料，以及其他 App 副本可能仍在使用的資料會被保留，Applications 檔案夾外的副本也會納入檢查。被其他副本使用的殘留會顯示位置和保留原因，無法勾選移除。無法確認歸屬或存取權限時，App 會保留該項目。

如何重新授予檔案夾存取權限？

開啟 SweepZen 的設定，重新授予相關檔案夾的存取權限。掃描時請選擇個人檔案夾。macOS 仍可能限制部分位置，SweepZen 無法繞過系統限制。

為什麼移除 App 需要授權 Applications 檔案夾？

/Applications 不在個人檔案夾內，SweepZen 將其中的 App 移到垃圾桶前，需要 macOS 的個別授權。你可以取消授權要求。

SweepZen 能移除系統層級的項目嗎？

需要管理者授權的項目可以在 Finder 中顯示，但 SweepZen 無法移除。系統工具中的指令會說明效果與代價，由你複製並自行執行；SweepZen 不會代你執行管理者指令。

背景項目和 Finder 選單如何處理？

SweepZen 顯示背景 App、延伸功能與 Finder 選單項目的來源。需要時，依頁面指引開啟 macOS 設定或停止服務。常見檔案類型的預設開啟 App 可以直接在 SweepZen 中選擇。這些工具不會自動刪除系統選單登錄項目。

SweepZen 會上傳我的檔案嗎？

不會。App 在本機處理檔案資訊，不發出網路要求，也不提供帳號、廣告、分析或上傳服務。隱私政策另行說明網站託管與支援郵件的處理方式。
