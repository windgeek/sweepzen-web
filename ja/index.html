ヘルプとサポート

Mac の中身を、もっとわかりやすく。

何が容量を占めているかを理解し、削除できるものを確認。決めるのはあなたです。

01 / スキャン

整理する前に確認

アプリのキャッシュやビルド成果物をスキャンします。各項目の内容と、削除すると何が変わるかを説明します。

02 / 探索

全体を見渡す

ストレージマップをカテゴリ別に確認し、フォルダをたどって容量の大きなファイルを見つけます。

03 / アンインストール

残すものも、自分で決める

アプリと関連ファイルを確認します。共有データは保護され、SweepZen 内で削除した項目はゴミ箱に移動します。

使い始めるには

  1. macOS 14 以降の Mac で SweepZen を開きます。
  2. 「スキャンして整理」「ストレージマップ」「アンインストール」のいずれかを選びます。「バックグラウンドと機能拡張」とツールボックスでは、別の確認・トラブル対処機能を利用できます。
  3. macOS に求められたら、ホームフォルダへのアクセスを許可します。アプリのアンインストールや一時ファイルの確認には、別のフォルダへの許可が必要な場合があります。許可はこの Mac に保存されます。
  4. 各結果と詳細を確認して、削除する項目を選びます。共有データや、所属を確認できない項目は保護されます。
  5. 確認リストを見直してから、選択した項目をゴミ箱に移動します。

よくある質問

空き容量が増えないのはなぜですか？

ゴミ箱に移動したファイルは、通常、引き続き容量を占めます。Finder で内容を確認し、不要と判断したらご自身でゴミ箱を空にしてください。APFS の共有ストレージやローカルスナップショットも、解放される容量に影響します。SweepZen はゴミ箱を空にせず、Time Machine のスナップショットも削除しません。

ファイルを元に戻すには？

Finder でゴミ箱を開きます。「戻す」が使える場合はそれを選ぶか、元の場所にファイルを移動してください。ゴミ箱からの復元は、空にするまで可能です。

項目がスキップされたり、残されたりするのはなぜですか？

保護対象のファイル、共有データ、別のアプリコピーがまだ使う可能性のあるデータは残します。Applications の外にあるコピーも確認対象です。別のコピーが使用する残存データには場所と保護理由が表示され、削除対象には選べません。所属やアクセスを確認できない場合も、その項目を残します。

フォルダへのアクセスを許可し直すには？

SweepZen の設定を開き、該当フォルダへのアクセスを許可し直してください。スキャンにはホームフォルダを選びます。macOS が一部の場所を引き続き制限する場合があります。SweepZen はその制限を回避できません。

アンインストールに Applications への許可が必要なのはなぜですか？

/Applications はホームフォルダの外にあるため、そこからアプリをゴミ箱に移動するには macOS の個別の許可が必要です。許可の要求はキャンセルできます。

システム領域の項目を削除できますか？

管理者の許可が必要な項目は Finder で表示できますが、SweepZen では削除できません。ツールボックスのコマンドには効果と負担の説明があります。コピーしてご自身で実行してください。SweepZen が管理者コマンドを実行することはありません。

バックグラウンド項目や Finder のメニューはどう扱いますか？

SweepZen はバックグラウンドのアプリ、機能拡張、Finder メニュー項目の出所を表示します。必要に応じて、macOS の設定やサービス停止の説明に従ってください。一般的なファイル形式を開くデフォルトのアプリは SweepZen で直接選べます。これらのツールがシステムのメニュー登録を自動で削除することはありません。

ファイルがアップロードされますか？

いいえ。アプリはファイル情報をローカルで処理し、ネットワークリクエストを行いません。アカウント、広告、利用状況分析、アップロードサービスもありません。ウェブサイトのホスティングとサポートメッセージの扱いは、プライバシーポリシーで別途説明しています。
