SweepZen アプリ

SweepZen はファイルとアプリの情報をお使いの Mac で処理します。ファイル、パス、スキャン結果、利用履歴、デバイス識別子、個人情報を開発者に収集・送信することはありません。アカウント、広告、第三者の分析 SDK、トラッキング機能はありません。

アプリにはネットワーククライアントの権限がなく、ネットワークリクエストを行いません。サポートやプライバシーのリンクはシステムのブラウザで開きます。

ローカルで使用する情報

スキャン、ストレージマップ、アプリの確認を依頼したとき、SweepZen はファイル名とパス、サイズと日付、アプリのメタデータ、実行中のアプリの情報を読み取ります。容量の用途を説明し、使用中のデータを保護するためです。データの所属を確認するため、一部の設定・出所情報のファイルもローカルで読み取ります。

フォルダへのアクセスは macOS が許可します。セキュリティスコープ付きのフォルダブックマークと、言語、外観、最後に完了した整理の日付などの設定は Mac に保存します。残存データの識別に役立てるため、一覧に表示したアプリの識別子と名前も記憶します。スキャン結果と選択内容は使用中のメモリに保持します。整理リストは、エクスポートしたときだけ、あなたが選んだ場所に保存します。

SweepZen 内で削除した項目は macOS のゴミ箱に移動します。アプリがゴミ箱を自動で空にすることはありません。フォルダへの許可後も、macOS が一部のファイルへのアクセスを制限する場合があります。

サポートメッセージ

開発者にメールを送ると、メールサービスがあなたのアドレス、本文、添付ファイルを処理します。これらは返信と問題の調査に使用し、サポートと適用される義務に必要な期間だけ保持します。私的なファイル、パスワード、機密情報を隠していないスクリーンショットは送らないでください。

GitHub の Issue は公開され、GitHub 自身のプライバシーステートメントに従って処理されます。代わりにメールを使うこともできます。サポートメールの削除を希望する場合は開発者にご連絡ください。ただし、適用される保存義務がある場合を除きます。

このウェブサイトと Apple のサービス

このサイトは GitHub Pages でホスティングされています。分析、広告、トラッキング Cookie、第三者のフォントは追加していません。GitHub はサービスの運用と保護のため、IP アドレスなどの技術的なリクエスト情報を処理する場合があります。

App Store での購入やダウンロード、あなたが Apple と共有する診断情報は、Apple 自身のポリシーとあなたの設定に従って Apple が扱います。
