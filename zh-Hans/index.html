开始使用

  1. 在运行 macOS 14 或更新版本的 Mac 上打开 SweepZen。
  2. 选择「扫描清理」「空间透视」或「卸载应用」。「后台与扩展」和系统工具提供独立的检查与故障排查功能。
  3. macOS 提示时，授予个人文件夹的访问权限。卸载应用或检查临时文件可能需要额外的文件夹授权，授权保存在本机。
  4. 查看每项结果及详情，再选择要移除的内容。共享数据及无法确认归属的项目会受到保护。
  5. 核对确认清单后，将所选项目移入废纸篓。

常见问题

为什么可用空间没有增加？

移入废纸篓通常不会释放文件占用的空间。请先在访达中确认文件，确定不再需要后自行清空废纸篓。APFS 共享存储与本地快照也会影响实际释放的空间。SweepZen 不会清空废纸篓，也不会删除 Time Machine 快照。

如何恢复文件？

在访达中打开废纸篓，使用可用的「放回原处」操作，或将文件移回原来的位置。清空废纸篓后，无法再通过废纸篓恢复。

为什么有些项目被跳过或保留？

受保护的文件、共享数据，以及其他应用副本可能仍在使用的数据会被保留，Applications 文件夹外的副本也会纳入检查。被其他副本占用的残留会显示位置和保留原因，不能勾选移除。无法确认归属或访问权限时，应用会保留该项目。

如何重新授予文件夹访问权限？

打开 SweepZen 的设置，重新授予相应文件夹的访问权限。扫描时请选择个人文件夹。macOS 仍可能限制部分位置，SweepZen 无法绕过系统限制。

为什么卸载需要授权 Applications 文件夹？

/Applications 不在个人文件夹内，SweepZen 将其中的应用移入废纸篓前，需要 macOS 的单独授权。你可以取消授权请求。

SweepZen 能移除系统级项目吗？

需要管理员授权的项目可以在访达中定位，但 SweepZen 不能移除。系统工具中的命令会说明效果与代价，由你复制并自行执行；SweepZen 不会代你运行管理员命令。

后台项目和 Finder 菜单如何处理？

SweepZen 显示后台应用、扩展与 Finder 菜单条目的来源。需要时，按页面指引进入 macOS 设置或停止服务。常见文件类型的默认打开应用可以直接在 SweepZen 中选择。这些工具不会自动删除系统菜单登记。

SweepZen 会上传我的文件吗？

不会。应用在本机处理文件信息，不发起网络请求，不设账户、广告、分析或上传服务。隐私政策另行说明网站托管与支持邮件的处理方式。
